Line Clearance Agent

Open a LAS or LAZ with any number of towers. The agent numbers the towers, marks every span in Potree and writes one Excel report per span.

Point cloud
Drop one or more .las / .laz files here
or
    Several files are merged into one cloud (for example the tiles of one line). The first file names the reports. Browse and pasted paths are used where they are. In the desktop app dropped files are used where they are too; in a browser they are copied into data\uploads first.
    Report header
    Screenshots are named prefix-1, prefix-2 … and prefix-Span.
    More options
    A guess is enough. Once the towers are counted you confirm the numbers at both ends.
    One row per tower: Tower, Latitude, Longitude. Each report gets its own tower's position.
    Only used for a one-tower file without a sheet.
    1. Open the point cloud in Potree
    2. Find and number the towers
    3. Mark each span
    4. Review and export

    Which towers are at the ends?

    In the viewer and in the line profile the towers are labelled from left to right. If one is not a real tower of this line, hover its number and click × to leave it out.

    Check the lines, then export

    Every span is marked. Look through the lines in Potree. To move one, drag either end point; the value updates as you drag.
